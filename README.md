# store-sales-data-analysis
# 🛒 Store Sales Data Analysis

## 📌 Project Overview
This project presents an Exploratory Data Analysis (EDA) of a retail store dataset using **Python** and **Pandas**. The analysis focuses on understanding sales performance, customer purchasing behavior, and identifying valuable business insights from the data.

---

## 🎯 Objectives
- Clean and preprocess the dataset.
- Explore sales performance.
- Identify top-selling products.
- Analyze customer purchasing behavior.
- Discover sales trends over time.
- Generate actionable business insights.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Jupyter Notebook

---

## 📂 Dataset
The dataset contains retail store transaction records, including product information, sales, customers, dates, and payment methods.

---

## 📊 Project Workflow
1. Data Loading
2. Data Inspection
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Business Insights
6. Conclusions

---

## 🔍 Business Questions
- Which products generate the highest revenue?
- What are the monthly sales trends?
- Which payment method is used most frequently?
- What is the average order value?
- Which time periods achieve the highest sales?
- How do customer purchasing patterns vary?

---

## 📈 Key Insights
- Identified the highest revenue-generating products.
- Analyzed monthly and daily sales performance.
- Explored customer purchasing behavior.
- Evaluated payment method usage.
- Generated insights to support business decision-making.
